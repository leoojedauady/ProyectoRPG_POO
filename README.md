# Proyecto RPG (Mija y Leo)
_Hecho con Java Maven y NetBeans_

**Integrantes**
- Leonardo Ojeda Vales
- Mijail Manrique

Diseñar e implementar en Java un pequeño modelo orientado a objetos que represente las
principales entidades y relaciones de un videojuego de tipo RPG (Role-Playing Game).
El proyecto deberá demostrar el uso correcto de los principales conceptos de
Programación Orientada a Objetos:
• Clases y objetos.
• Encapsulamiento.
• Herencia.
• Clases abstractas.
• Interfaces.
• Polimorfismo.
• Composición.
• Agregación.
